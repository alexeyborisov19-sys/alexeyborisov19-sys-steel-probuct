## 1. Выявленный факт

Техническая диагностика 13 августа 2026 года выявила семь ранних заявок формы,
созданных 3 августа 2026 года, для которых отсутствуют отдельные файлы
`consent-audit`.

Для каждой из семи заявок в неизменённом первичном JSON имеются:

- флаг предоставленного согласия;
- событие `quote_request_consent`;
- дата и время записи;
- клиентская отметка времени;
- версия согласия на обработку персональных данных;
- версия политики;
- хешированный сетевой идентификатор.

Открытые персональные данные в настоящий акт не включаются. Перечень технических
requestId помещается в закрытое приложение, если это потребуется юристу.

## 2. Принятое техническое решение

1. Первичные JSON не изменять.
2. Отдельные consent-audit задним числом не создавать.
3. При проверке целостности сохранять статус `MISSING_CONSENT_AUDIT` как честное
   историческое исключение.
4. При официальной выгрузке раскрывать ответственному факт исключения и
   включать только реально существующие доказательства.
5. Юристу определить достаточность встроенного события применительно к
   конкретному запросу/спору и необходимость дополнительных организационных
   действий.

## 3. Проверка последующей работы

Для заявок после указанного периода отдельный consent-audit формируется штатно.
Любое новое отсутствие файла требует расследования как отдельный инцидент или
ошибка целостности.
