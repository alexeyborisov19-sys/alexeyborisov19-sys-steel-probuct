# Лист согласования публичных юридических документов сайта

**ПРОЕКТ — НЕ УТВЕРЖДЕНО**

## 1. Документы для проверки

1. Политика обработки персональных данных — `/legal/privacy`.
2. Согласие на обработку персональных данных —
   `/legal/personal-data-consent`.
3. Согласие на рекламные и информационные материалы —
   `/legal/marketing-consent`.
4. Политика cookies — `/legal/cookies`.
5. Сервисы обработки данных — `/legal/services`.
6. Пользовательское соглашение — `/legal/terms`.
7. Реквизиты Оператора — `/legal/requisites`.

## 2. Проверка содержания

- [ ] Реквизиты Оператора подтверждены выпиской/корпоративными документами.
- [ ] Цели, категории субъектов и данных соответствуют фактическим формам.
- [ ] Согласие определяет субъекта и порядок его идентификации по имени,
      контактному реквизиту, времени и техническому номеру заявки; для
      реализации прав допускается запрос достаточных подтверждающих сведений.
- [ ] Правовые основания определены по каждой цели.
- [ ] Сроки и порядок уничтожения утверждены.
- [ ] Рекламное согласие отделено от обязательного согласия формы.
- [ ] Яндекс Метрика и обращения к `mc.yandex.ru`/`mc.yandex.com` разрешаются
      только после выбора пользователя; поля заявки и файлы в Метрику не
      передаются.
- [ ] В исходном коде нет неиспользуемого разрешения `images.unsplash.com`.
- [ ] Вебвизор и внешние ИИ/мессенджеры описаны по фактическому статусу.
- [ ] Первичные базы находятся в РФ.
- [ ] Перечень сервисов соответствует фактическим договорам и потокам.
- [ ] Закрытая admin-система описана как технически развёрнутая, но выключенная.
- [ ] Не заявлено о реально выполненных официальных выгрузках или удалениях.
- [ ] Порядок обращений, отзыва и контакты понятны субъекту.
- [ ] Сведения об historical consent-audit exception не искажаются внутренними
      документами и не создаются задним числом.
