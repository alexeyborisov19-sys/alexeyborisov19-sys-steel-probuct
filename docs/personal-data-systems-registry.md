# Реестр информационных систем и подрядчиков

Реестр описывает цель, поставщика, страну баз, категории данных, основание, договор, сроки, ответственных, администраторов, MFA, экспорт, удаление и дату пересмотра.

Стартовый перечень для ручной проверки: VPS Beget, Beget Object Storage, корпоративная почта, Яндекс Метрика, GitHub только для исходного кода без клиентских ПДн, административная SQLite, первичные JSON-каталоги, карантин, consent-audit и процесс шифрованного backup.

Система не создаёт эти записи автоматически и не объявляет неподтверждённые сведения фактом. До проверки договора, фактического потока и страны базы применяется статус `REVIEW_REQUIRED`/аналогичный. Изменение выполняет только роль с `MANAGE_SYSTEMS_REGISTRY` и создаёт audit event.
