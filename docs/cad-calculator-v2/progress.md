# Прогресс

## Реализовано

- Компактный первый экран и единая загрузка вместо трёх пустых панелей.
- После загрузки: сворачиваемая спецификация, крупный viewer и параметры справа.
- Материал по умолчанию явно обозначен; данные модели отделены от пользовательского выбора.
- Видимый состав дополнительных операций, вариант неизвестного норматива, масштаб 2D, reduced motion.
- Цена проекта и PDF/печать в области конфигурации; ID и фиксированное время получения результата.
- Отмена запросов и epoch-проверка защищают от старой цены.
- Серверная проверка конфликтов количества гибов.
- Исправлен выбор свежего прайса; во внутреннем входе добавлен статус источников.
- Найден и проверен живой Atlantik PDF adapter.
- Создан самостоятельный интерфейс сотрудников ProductionApplication и общий useCadProject.
- Добавлены спецификация, групповые изменения материала/количества, вкладки цен и сохранённого ИИ-контроля.
- Найден ранее внедрённый quote-engine (#157); используется существующий CAD-аудит. Подробности в legacy-ai-inventory.md.

## Следующие обязательные этапы задания

1. Авторизованная браузерная приёмка самостоятельного производственного приложения.
2. Дублирование позиций и сравнение партий. Групповое изменение материала и количества уже добавлено.
3. Проверяемое распределение листов (настоящий nesting), ограничения поворотов/остатков.
4. Версионированная ценовая база для воспроизведения старых отчётов; полная проверка передачи файлов и ревизий.
5. Расширенная эталонная геометрия, кеш анализа STEP, нагрузка/память/параллельные запросы.
6. Авторизованный внутренний браузерный сценарий на отдельной тестовой базе и утверждённых нормах.
7. Проверка состояния production-таймера штатным workflow в режиме check, затем выпуск только после приёмки.

Эти пункты не реализованы данным этапом. Нет новых платных API или изменений кассетного калькулятора.
