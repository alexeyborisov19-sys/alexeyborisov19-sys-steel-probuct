# Модуль «КП → заявка в производство → папка заказа → Bitrix24»

Статус: отдельное внедрение в Draft PR #173. Рабочий CAD-калькулятор, `main` и production не меняются.

## Целевой маршрут

1. Внутренний CAD-калькулятор завершает расчёт.
2. Менеджер открывает зафиксированный производственный расчёт.
3. Указывает номер КП, название КП, заказчика, сроки, приоритет и ответственного.
4. При необходимости корректирует наименование, количество и примечание цеху по каждой позиции.
5. Из расчёта строится единый `ProductionOrder`.
6. Сервер создаёт папку `<номер КП> <название КП>` внутри сохранённой корневой папки заказов.
7. В корень папки сохраняются:
   - `КП <номер>.pdf`;
   - `Заявка в производство <номер>.pdf`;
   - `order-manifest.json`.
8. Исходные файлы раскладываются только в реально используемые подпапки: `CAD`, `Чертежи`, `Вложения`.
9. Кнопка «Создать заявку в Bitrix» создаёт сделку в явно настроенных воронке и стадии. Повторный запуск обновляет ту же сделку по `ORIGIN_ID`, а не создаёт дубль.

## Рабочие страницы

- `/internal/production-order` — выбор зафиксированного производственного расчёта;
- `/internal/production-order/from-calculation/<fileName>` — редактор КП и производственной заявки;
- `/internal/production-order/settings` — выбор и сохранение корневой папки заказов.

## Настройка папки заказов

На странице настройки доступны:

- поле для ручного ввода абсолютного пути;
- кнопка `Обзор`, которая открывает системный выбор папки на компьютере, где запущен Next.js-калькулятор;
- кнопка `Сохранить путь`;
- проверка, что папка существует и доступна для записи;
- сохранение пути после перезапуска приложения.

Сохранённое значение записывается в закрытый файл:

`<STEEL_PRODUCT_PRIVATE_SETTINGS_ROOT или ~/.steelprodukt>/production-order-storage.json`

Сохранённый через интерфейс путь имеет приоритет над `STEEL_PRODUCT_ORDER_ROOT`. Переменная окружения остаётся резервным вариантом для серверного развёртывания.

Важно: системное окно `Обзор` открывается на том компьютере, где выполняется сервер приложения. При работе через удалённый сервер абсолютный путь вводится вручную либо разрешается удалённый вызов отдельной настройкой.

## Создание папки заказа

Защищённый endpoint:

`POST /api/internal/production-order/package`

Он:

- принимает только проверенный `ProductionOrder`;
- использует сохранённый корневой путь;
- создаёт папку и `order-manifest.json`;
- не создаёт дубль при повторном вызове для того же `orderId`;
- обновляет существующий манифест того же заказа;
- блокирует перезапись папки другого заказа;
- блокирует использование уже заполненной посторонней папки без манифеста;
- заранее возвращает пути будущих PDF КП и производственной заявки.

## Ограничения текущей версии

- до 50 деталей в одной заявке;
- файловый корень находится вне `public/`;
- выбранная папка должна существовать и быть доступна процессу Node.js для записи;
- Bitrix webhook хранится только в серверных переменных окружения;
- коды пользовательских полей Bitrix никогда не угадываются: они задаются картой `BITRIX_ORDER_FIELD_MAP_JSON`;
- печатная форма не показывает внутренние ставки/себестоимость;
- пустые разделы файлов, доставки и операций не выводятся;
- автоматическая генерация и запись двух PDF пока не подключена;
- копирование исходных CAD/чертежей ожидает адаптер к фактическому серверному хранилищу загруженных файлов.

## Переменные окружения

```text
# Резервный путь, если путь ещё не сохранён через интерфейс
STEEL_PRODUCT_ORDER_ROOT=\\\\SERVER\\Production\\Orders

# Необязательно: отдельное место для закрытого файла настроек
STEEL_PRODUCT_PRIVATE_SETTINGS_ROOT=/private/app-settings

# По умолчанию системный обзор разрешён только через localhost
STEEL_PRODUCT_NATIVE_FOLDER_PICKER_ALLOW_REMOTE=false

BITRIX_ORDER_INTEGRATION_ENABLED=true
BITRIX_WEBHOOK_URL=https://<portal>.bitrix24.ru/rest/<user>/<token>
BITRIX_ORDER_CATEGORY_ID=<numeric category id>
BITRIX_ORDER_STAGE_ID=<stage id>
BITRIX_ORDER_FIELD_MAP_JSON={"quoteNumber":"UF_CRM_...","orderFolder":"UF_CRM_...","dueDate":"UF_CRM_...","projectId":"UF_CRM_...","partsCount":"UF_CRM_..."}
```
