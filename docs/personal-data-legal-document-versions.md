# Версии юридических документов

Регистрируются `PRIVACY_POLICY`, `PERSONAL_DATA_CONSENT`, `MARKETING_CONSENT`, `COOKIE_POLICY`, `USER_AGREEMENT` и `OTHER`.

Запись хранит версию, даты действия, SHA-256 содержимого, закрытый archive path, статус, утверждающего и основание. Старую версию нельзя перезаписывать: изменение содержания создаёт новую запись.

Consent-audit должен ссылаться на версию, фактически показанную пользователю. Сам регистр не доказывает публикацию или утверждение: файл должен быть архивирован, хеш проверен, а решение — оформлено уполномоченным лицом. Production backfill задним числом запрещён.
