# Калькулятор сотрудников — отдельный выпуск

Владелец продолжает использовать установленное Mac-приложение без реестра активаций. Google Диск не используется. Windows-кандидат собирается в закрытом репозитории `alexeyborisov19-sys/steelprodukt-employee-desktop`. Исходные цены, персональные проекты и ключи не входят в установщик.

Сервис выключен по умолчанию. Для включения нужны частные абсолютные пути:

- `STEEL_EMPLOYEE_ACTIVATION_ENABLED=true`
- `STEEL_EMPLOYEE_REGISTRY_PATH`: отдельная SQLite-база, доступ на запись только пользователю приложения.
- `STEEL_EMPLOYEE_BASIS_PATH`: утверждённый исходный прайс JSON.
- `STEEL_EMPLOYEE_SETTINGS_PATH`: только объект утверждённых settings; без истории пользователей и ключей.
- `STEEL_EMPLOYEE_RELEASE_PATH`: проверенные version, url, sha256, bytes установщика.
- `STEEL_EMPLOYEE_INSTALLER_PATH`: только проверенный EXE; открытая ссылка выдаёт этот файл, не каталог.

Управление: `/internal/personal-data/employee-app`, действующая авторизация администратора, повторное подтверждение пароля и CSRF для изменений. Код показывается один раз. Реестр хранит хеши, а не код и токен. Блокировка запрещает новые расчёты после окончания минутного кеша; сохранённые данные остаются локально. Считаются активированные установки, а не скачивания. Привязка к случайному ID установки не является защитой от намеренного копирования или модификации локального кода.

Перед выпуском обязательны Windows-сборка, запуск упакованной программы, установка/повторная установка, сохранность локальных расценок, тест реальной активации и отзыва. Неподписанное обновление загружается с проверкой SHA-256 и запускается сотрудником вручную. Контрольная сумма не заменяет цифровую подпись издателя.

Публикация допускается только после приёмки конкретной сборки. Эти переменные не нужно добавлять в публичные клиентские настройки. Включение сервиса не должно изменять существующие права администратора, настройки рекламы или юридические документы.
