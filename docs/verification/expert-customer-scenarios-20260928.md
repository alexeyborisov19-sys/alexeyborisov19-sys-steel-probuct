# Семь экспертных клиентских сценариев — 28.09.2026

Это проверка сайта специалистом с автоматизацией браузера Chrome, а не исследование с семью реальными людьми. Она проверяет доступность действий, сохранность данных, ответы сервера и восстановление после ошибок. Она не измеряет понимание текста человеком, конверсию или время выполнения задачи новым пользователем.

База: опубликованный main 46fd1a3, PR #183. Проверены живой сайт и локальная production-сборка. POST `/api/quote` в сценариях отправки перехватывается; реальные заявки, письма и CRM-сообщения не создаются. Расчётные API вызываются реально, на синтетических деталях и репозиторном STEP.

## Исправление

Калькулятор металлокассет передаёт тип, способ ввода, толщину, размеры стены/проёмы либо исходную площадь, рассчитанную площадь и количество. Даже до получения результата переход к инженеру не обнуляет параметры. Вводимые через URL значения ограничены числовым форматом; неподдерживаемый тип и толщина не подставляются. Параметры остаются заявленными клиентом и требуют проверки специалистом. Денежные значения из URL не подставляются: прежняя защита от неподтверждённой цены сохранена.

Формулы, тарифы, логотип, защищённая фраза главной, «Решения для объектов» и юридические согласия не изменены.

## Что ещё мешает бесшовному пути

- CAD-файлы требуется прикрепить в форме повторно; предупреждение видно. Автоматическую передачу файлов эта доработка не реализует.
- Экран ручного ввода пяти изделий остаётся длинным на телефоне. Лимиты и редактирование работают, но удобство массового ввода нужно проверить с людьми.
- Множество вторичных блоков делает страницу контактов длинной; форма находится раньше них. Само по себе отсутствие переполнения не доказывает удобство.
- Расчёт остаётся предварительным. Нужна проверка технологом для конкретного изготовления; сайт не обещает автоматический производственный допуск.

## Воспроизводимость и статус

Команды: `qa-site-ux.mjs`, `qa-public-manual.mjs` с live URL, `qa-customer-journey.mjs`, новый `qa-expert-handoff.mjs`. Последний проверяет полноту передачи параметров и недоступный расчёт. Браузерные сценарии базовой версии прошли, кроме воспроизведённой потери параметров; исправленный переход прошёл локально. Полная финальная проверка и публикация фиксируются в журнале разработки.

Оценка: один подтверждённый дефект передачи данных устранён; автоматизированные сценарии дают техническое подтверждение, но не основание объявить сайт «10 из 10» или повысить оценку реальной конверсии.
