- Из них 894 строки имеют TOTAL_SHOWS > 0; 34 строки — 0 показов. Оба ответа API count=894. Разность 928−894=34 совпадает с числом нулевых строк. Это наблюдаемая сверка, не документированная гарантия семантики count.

## Исключения
Не относить к прямому коммерческому спросу запросы «что такое», «монтаж», «допуски», «схема», выставочные запросы. Не добавлять чужие бренды и домены в наши title. Не добавлять Липецк, Миасс, Новосибирск или иные города в географию услуг только потому, что они встретились в запросах. Не обещать монтаж или пожарные свойства.
Юридические тексты, согласия, оборудование, цены, сроки и ограничения географии не изменяются.
Техническая основа, URL и canonical не требуют изменений для этого пакета.
