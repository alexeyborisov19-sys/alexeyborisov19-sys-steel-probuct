# Rollback административной системы ПДн

## Немедленное безопасное состояние

1. Оставить или вернуть сохранённое `PD_ADMIN_ENABLED=false`.
2. Перезапустить только приложение с `--update-env`, если environment менялся.
3. Убедиться, что internal pages и API возвращают 404.
4. Проверить публичный сайт, quote form, ИИ-инженера и SMTP.
5. Не открывать внешний порт 3000 и не ослаблять Nginx/firewall.

## Данные

- не удалять и не изменять первичные JSON, consent-audit и карантин;
- сохранить проблемную SQLite, WAL/SHM и обезличенные журналы для расследования;
- не запускать legacy cleanup `--apply`;
- не «исправлять» audit chain;
- не откатывать миграции удалением таблиц;
- восстановление SQLite выполнять только из проверенной зашифрованной backup в
  отдельный путь, проверить integrity и только затем согласовать замену.

## Код

Вернуть предыдущий проверенный commit штатным deployment-механизмом, выполнить
`npm ci`, тесты и build, затем `pm2 startOrReload ... --update-env`. Не удалять
`/var/lib/steelprodukt`. После восстановления зарегистрировать инцидент с
фактическим временем и действиями; записи задним числом не создавать.
