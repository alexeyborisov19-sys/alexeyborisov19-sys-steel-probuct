# Реестр инцидентов

Статусы: `OPEN`, `ASSESSMENT`, `CONTAINED`, `NOTIFICATION_REQUIRED`, `NOTIFIED`, `INVESTIGATION`, `REMEDIATION`, `CLOSED`.

Запись включает дату выявления, описание, системы и категории, оценку числа субъектов, первичные меры, ответственное лицо, оценку необходимости уведомления, даты уведомлений, расследование и remediation. Она может быть связана с заявками; открытая связь блокирует удаление.

Приложение не принимает автоматически решение об уведомлении Роскомнадзора и не отправляет уведомление. Ответственный документирует оценку, канал и время фактического действия. Статус `CLOSED` требует результата расследования и принятых мер.

События: `INCIDENT_CREATED`, `INCIDENT_UPDATED`, `INCIDENT_NOTIFICATION_RECORDED`, `INCIDENT_CLOSED`.
