# Регламент прекращения обработки и уничтожения персональных данных

Статус: рабочий шаблон для утверждения приказом ООО «ЭНЕРГОАЛЬЯНС».

## 1. Основания

Процедура запускается, когда наступило предусмотренное законом основание, в том числе достигнута цель обработки, выявлена неправомерная обработка, поступил обоснованный отзыв согласия или требование субъекта, предписание Роскомнадзора либо иное основание, предусмотренное № 152-ФЗ.

Отзыв согласия не означает автоматическое уничтожение всех данных, если у Оператора сохраняется самостоятельное законное основание или обязанность хранения по договору, бухгалтерскому, налоговому, архивному или иному законодательству. В таком случае обработка ограничивается соответствующей законной целью.

## 2. Ответственные

1. Ответственный за организацию обработки ПД принимает и регистрирует основание.
2. Владелец соответствующего бизнес-процесса подтверждает наличие или отсутствие действующей цели/обязанности хранения.
3. Администратор информационной системы выполняет техническое блокирование/удаление только по зарегистрированному заданию.
4. Результат контролируется ответственным за ПД или назначенной комиссией.

## 3. Порядок

1. Зарегистрировать запрос или внутреннее основание: дата, субъект, канал, требуемое действие, инициатор.
2. Достоверно определить относящиеся к субъекту записи без раскрытия данных постороннему заявителю.
3. Проверить договорные, бухгалтерские, налоговые, судебные, претензионные и иные обязательные сроки хранения.
4. Определить все места обработки: рабочая база, файлы заявок, корпоративная почта, CRM/служебные системы, локальные копии, журналы, выгрузки и резервные копии.
5. При необходимости немедленно ограничить доступ или заблокировать обработку до завершения проверки.
6. Уничтожить данные в действующих системах в предусмотренный законом срок либо зафиксировать законное основание продолжения ограниченного хранения.
7. Для резервных копий исключить обычное использование удалённых данных и обеспечить их уничтожение при ближайшей предусмотренной ротации/перезаписи в соответствии с утверждённым сроком хранения резервных копий. При восстановлении из старой копии повторно применить список удалений до возврата системы в эксплуатацию.
8. Получить подтверждение от привлечённых обработчиков об удалении, если данные были переданы им по поручению.
9. Проверить результат выборочным поиском по идентификаторам субъекта.
10. Оформить подтверждение уничтожения.

## 4. Подтверждение уничтожения

В соответствии с приказом Роскомнадзора от 28.10.2022 № 179:

- при неавтоматизированной обработке оформляется акт об уничтожении;
- при автоматизированной обработке сохраняются акт об уничтожении и выгрузка из журнала регистрации событий информационной системы;
- документы должны содержать сведения, предусмотренные действующими требованиями приказа № 179, и храниться в установленный им срок.

Нельзя считать достаточным подтверждением одно устное сообщение администратора, удаление записи из интерфейса или отсутствие записи в поиске.

## 5. Контроль сроков

Ответственный за ПД ведёт контрольный журнал с датой получения основания, применимым сроком по № 152-ФЗ, датой блокирования, датой фактического уничтожения, номером акта и ссылкой на подтверждающий журнал событий.

## 6. Запреты

- Не использовать общие аккаунты администраторов для операций уничтожения, если можно идентифицировать конкретного сотрудника.
- Не удалять сведения, которые организация обязана хранить по закону, только ради формального исполнения отзыва согласия.
- Не оставлять экспортированные архивы, временные файлы и локальные копии после закрытия задания.
- Не восстанавливать удалённые данные из резервной копии в рабочий контур без повторного применения списка уничтожения.
