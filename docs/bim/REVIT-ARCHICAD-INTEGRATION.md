# Revit и Archicad: проверка IFC библиотеки «Сталь Продукт»

Документ описывает найденные открытые инструменты. **Ни один инструмент не установлен на production, нативные RFA/RVT/GSM здесь не обещаются.**

## Revit
- RevitMCP: https://github.com/oakplank/RevitMCP — локальный мост к открытой сессии Autodesk Revit через pyRevit и MCP.
- Autodesk/revit-ifc: https://github.com/Autodesk/revit-ifc — исходники поддержки IFC в Revit; использовать официальные и совместимые версии.
- На компьютере проектировщика требуются установленный Revit, pyRevit и открытый тестовый проект. Не открывайте локальный сервер в общедоступный интернет.

## Archicad
- archicad-mcp: https://github.com/Boti-Ormandi/archicad-mcp — локальный MCP-мост к официальному JSON API, при необходимости с Tapir.
- Официальная Python API Graphisoft: https://archicadapi.graphisoft.com/getting-started-with-archicad-python-connection
- Для проверки нужен установленный Archicad и открытый тестовый проект.

## Независимый слой
- IfcOpenShell: https://github.com/IfcOpenShell/IfcOpenShell — чтение IFC4, проверка EXPRESS, OCCT геометрии, координат, единиц.
- В данном репозитории работает `scripts/verify-oriented-cassettes.py` через IfcMCP и IfcOpenShell; публичный MCP-сервер не запускается.

## Что проверить в нативных программах
1. Импорт обоих альтернативных IFC по отдельности, без дублирования кассеты.
2. Единицы миллиметры, размеры bounding box, вертикальная ось +Z.
3. Верхний угловой зацеп именно сверху у SP-CAS-01, SP-CAS-03, SP-CAS-05; прямые и угловая модель — без переворота профиля.
4. Геометрия отверстий и гибов; корректность показа в планах, фасадах, 3D; отсутствие потери поверхности.
5. Проектные атрибуты, идентификаторы, расположение повторных экземпляров; сверка при экспорте/импорте обратно.
6. Только после действительной проверки в конкретной версии Revit/Archicad отмечать совместимость. Отдельно создавать нативные параметрические семейства по утверждённым правилам изделия.

## Серии продукции без новой классификации BIM
По опубликованным коммерческим страницам: Стандарт — открытый крепёж (SP-CAS-02/04/06); Премиум — скрытый (SP-CAS-01/03/05). Слова «стандартная кассета» в других именах не доказывают принадлежность к товарной серии. Для «Ажур» (перфорация) и «Рельеф» (3D-рельеф) в текущих образцах отсутствует подтверждённая специализированная модель. Названия добавляются в существующие карточки без перегруппировки.
