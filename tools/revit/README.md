# Revit RFA — начало отдельного конвейера Steel Produkt

## Выбранный стек
**Autodesk Revit API + pyRevit**, а для управляемого локального взаимодействия с открытым Revit — [oakplank/RevitMCP](https://github.com/oakplank/RevitMCP). Это позволяет работать с настоящим редактором семейств Revit, а не выдавать IFC за параметрическое RFA. [Draw2RFA](https://github.com/ManfieldLi/Draw2RFA-Revit) пока alpha и поддерживает только базовые прямоугольные/круглые экструзии, поэтому его нельзя считать точным конвертером кассет с отверстиями, бортами, рустами и замками.

## Готовый первый этап
`python3 tools/revit/build_source_jobs.py --out /tmp/steelprodukt-revit-jobs.json`

Генератор считывает **все 15 изделий** существующей BIM-библиотеки, проверяет наличие обоих IFC4-представлений и SHA-256 координационных файлов относительно каталога. Для SP-CAS-01, -03, -05 выбирает исправленные IFC с верхним замком +Z; для остальных — исходные. Генерирует машиночитаемое задание для будущего изготовления семейств с SHA-256 всех 30 входных файлов.

Это проверенный исходный список задач, **не** RFA и **не** заявление о завершении моделирования.

## Следующий инженерный этап в Revit
1. На авторизованном Windows-компьютере с Revit и pyRevit открыть тестовые файлы; локальный RevitMCP не публиковать в интернет.
2. Для каждого типа создать отдельное семейство в корректной категории с референсными плоскостями и реальными зависимостями Width/Height/Thickness, материалом и свойствами исполнения.
3. Геометрию борта, руста, отверстий, радиусов и верхнего замка проверять относительно эталонного IFC/STEP при нескольких значениях размеров; не подменять трёхмерные замки прямоугольными экструзиями.
4. Экспортировать/переимпортировать семейство и сравнить размеры, профиль, количество отверстий, соединения и идентификаторы. Проверить отдельно фасадные стыки и доступность монтажа.
5. Только после этих проверок подписать конкретную модель как готовый нативный RFA, разместить в каталоге и отдельно опубликовать.

## Границы
Ни один файл сайта или исходного BIM-релиза не меняется. Нет подключения к установленному Revit, нет создания .rfa, нет подтверждения импорта/совместимости или узлов. Никакого автоматического деплоя на Beget.
