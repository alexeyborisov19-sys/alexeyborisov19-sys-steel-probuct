# Сталь Продукт — v0.1.3

Стартовая версия корпоративного сайта «Сталь Продукт». Проект использует Next.js 15, App Router, TypeScript, Tailwind CSS и Framer Motion.

## Запуск локально

Требуется Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Production-сборка

```bash
npm run build
npm run start
```

## Структура

- `app/` — маршруты и глобальные стили App Router.
- `components/` — повторно используемые компоненты интерфейса.
- `data/` — контентные данные, которые позднее можно перенести в CMS.
- `public/` — брендовые файлы и изображения.

## Брендовый логотип

Утверждённый логотип размещён в `public/logo/steel-product.png` и используется единым компонентом `components/Brand.tsx` в Header и Footer.

## Каталог для менеджеров и печати

Актуальный переработанный каталог фасадных решений доступен в `public/documents/katalog-fasadnyh-resheniy-stal-produkt.pdf`. Это версия для печати на чисто белых листах в формате A4 с вылетами по 3 мм: графитовый текст, фирменные оранжевые акценты и очищенные технические рисунки без вставленных страниц исходного каталога.

Для короткой презентации есть `public/documents/katalog-fasadnyh-resheniy-kratkij-4-stranicy.pdf`: четыре последовательные страницы A4 для двусторонней печати на двух листах. Исходный скрипт - `work/generate_compact_print_catalog.py`.

Исходный файл находится в `work/generate_updated_catalog.py`. После правок запускайте его из корня проекта через Python с установленными `reportlab` и `Pillow`, затем копируйте результат в `public/documents/`. В каталоге используются действующие контакты и адрес производства: `г. Смоленск, Рославльское шоссе, 7-й км, стр. 3`.

## Деплой на Beget

На VPS установите Node.js 20+, затем:

```bash
git clone https://github.com/alexeyborisov19-sys/alexeyborisov19-sys-steel-probuct.git
cd alexeyborisov19-sys-steel-probuct
npm install
npm run build
npm run start
```

Для постоянной работы используйте `pm2`, а перед Node.js настройте Nginx как reverse proxy.

Для ручной публикации и будущих обновлений по вашему решению используйте [DEPLOYMENT.md](DEPLOYMENT.md). В проект включена PM2-конфигурация для стабильной работы сайта на VPS.

## Заявки с чертежами

Страница `/contacts#contact-form` принимает до 10 файлов суммарным объёмом до 25 МБ: PDF, DXF/DWG, STEP/IGES, CAD-файлы, изображения, офисные документы и архивы.

Для фактической отправки заявок на `info@steelprodukt.ru` скопируйте `.env.example` в `.env.local` и внесите SMTP-параметры почтового ящика. На Beget эти же переменные добавляются в окружение процесса `pm2`; пароль почты не должен попадать в Git.

Для Nginx на VPS дополнительно задайте `client_max_body_size 30m;`, иначе сервер может отклонить чертежи до передачи в приложение.
