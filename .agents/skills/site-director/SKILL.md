# Site Director

Coordinate substantial website work as one pipeline rather than independent edits.

## Required sequence
1. Inspect the existing implementation and relevant project context.
2. For product/manufacturing claims, use `manufacturing-technical-writer` first. Never invent standards, dimensions, tolerances, materials, loads, certifications, machine capabilities, or performance values.
3. For discoverability and conversion structure, use the installed SEO/marketing skills, including `seo-audit`/`ai-seo` when relevant.
4. For visual direction and UX, use `ui-ux-pro-max` before implementation when the task changes layout, hierarchy, typography, interaction, or responsive behavior.
5. Use `website-development` and the Superpowers workflow for implementation planning, code changes, tests, debugging, and verification.
6. Run the `site-quality-gate` before declaring the work complete.

## Orchestration
If Ruflo MCP tools are available, use Ruflo to coordinate independent research/review tasks in parallel, but keep one clear implementation owner. Do not parallel-edit the same files without isolation.

## Decision rule
A page is not complete because it builds. It is complete only when product facts, SEO intent, visual hierarchy, responsive behavior, browser behavior, performance risk, accessibility, security, and code quality have all been checked to the extent relevant to the change.
