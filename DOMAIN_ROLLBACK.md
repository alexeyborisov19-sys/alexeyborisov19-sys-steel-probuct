# Резервная точка — сайт №1

Снимок перед переключением домена на новую версию «Сталь Продукт».

## Текущая рабочая версия №1

- Адрес: `https://www.steelprodukt.ru/`
- Платформа: Tilda (по заголовкам ответа сервера)
- DNS на 22 июля 2026 года:
  - `steelprodukt.ru` — A — `176.57.67.112`
  - `www.steelprodukt.ru` — A — `176.57.67.112`

## Быстрый откат

В панели DNS Beget вернуть две A-записи на `176.57.67.112`. После обновления DNS домен снова будет открывать сайт №1. Файлы и настройки текущего сайта №1 при переключении не изменяются.

- Тестовый адрес Node.js-приложения: `http://31.129.103.48:3000/`
